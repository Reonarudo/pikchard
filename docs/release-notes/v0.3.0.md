### Features

- **The shape you are editing glows.** Put the cursor on a line and the shape it draws lights up in the diagram — inside containers too, and for a shape a macro made. Together with clicking a shape to select its code, the two directions now meet.
- **Copy Link.** File ▸ Copy Link copies a link that opens your script in the browser. The script travels inside the link, so no server ever sees it. Opening one never replaces unsaved work without asking.
- **Export All Diagrams….** Every diagram of a Markdown file, as SVGs in one `.zip`. A script with an error is left out, and you are told which.
- **Copy Script as Markdown.** The script, exactly as written, inside a ` ```pikchr ` block, ready to paste into a Markdown file.
- **The desktop looks for updates by itself,** at most once a day, and tells you once about each new release. Help ▸ Check for Updates… still answers whenever you ask.

The first release of Pikchard, a live editor for [Pikchr](https://pikchr.org) diagrams, as a web app and a desktop app for macOS, Windows and Linux.

### Features

- **Live diagram.** The diagram redraws as you type, with Zoom In, Zoom Out, Actual Size and Fit to View. If the script has an error, the error is shown at the line where it happened, and the last diagram that rendered stays visible.
- **An editor that knows Pikchr.** Syntax highlighting, bracket matching and auto-closing, and a link to the Pikchr Language Manual.
- **Markdown files with several diagrams.** Each `pikchr` fenced block is its own script. The diagram follows the cursor, Next Script and Previous Script jump between them, and Insert Pikchr Diagram adds a new one.
- **Files.** New, Open… (also by dropping a file on the window), Save and Save As…, and Recent. Unsaved work is kept between sessions and offered back on the next launch.
- **Export.** Export SVG…, Export PNG… and Copy Diagram.
- **Examples.** Eight bundled examples in the Examples menu.
- **Light and dark themes,** following the system until you choose one. The diagram is redrawn for the theme.
- **Keyboard first.** Every command is in the menus and works from the keyboard, most of them with a shortcut. Hide Editor gives the diagram the full window, and the split between the two panes can be resized.
- **Desktop.** `.pikchr` files open in Pikchard with a double-click, and Pikchard appears under "Open With" for Markdown. One window is reused, and it remembers its size and position. The macOS build is signed and notarized.
- **Web.** Runs entirely in the browser with no server, and works offline after the first visit. A new version waits for you to click Reload.
